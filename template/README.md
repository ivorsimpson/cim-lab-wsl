# __PROJECT_NAME__

CUDA C++ project generated by the Sussex lab-gpu bootstrap.

## Quick start
1. Install the recommended extensions when VS Code prompts.
2. Press F7 to build.
3. Press Shift+F5 (or Tasks: Run Test Task) to run.
4. Press F5 to debug with cuda-gdb (kernel breakpoints).

Expected output:
```
Device:       NVIDIA RTX A4000
Compute cap:  8.6
OK: 1048576 elements, all correct.
```

## Troubleshooting
- "nvcc: command not found" - open a new terminal so the conda env activates.
- Segfault on launch - check CMAKE_CUDA_ARCHITECTURES matches your GPU.
- nvidia-smi missing - the Windows NVIDIA driver may need updating.
- Any GPU call hangs forever - run `wsl --shutdown` in PowerShell on Windows,
  then re-open the WSL terminal. Stale dxg state in a long-lived distro is
  the usual cause.
